# WA Business Desk — WhatsApp Business SaaS

> **সার্ভার ছাড়া, ক্লিক করেই ফ্রিতে চালাতে চান?** [`whatsapp-cloudflare/`](../whatsapp-cloudflare/README.md) ভার্সনটি ব্যবহার করুন — এক ক্লিকে Cloudflare-এ চালু হয়।

WhatsApp Business-কে একটা ওয়েব অ্যাপ বা SaaS-এ নিয়ে আসার সিস্টেম। এখানে **মালিক** বা **অ্যাডমিন** টিমে সদস্য যোগ করতে পারবেন। তারপর সবাই একসাথে একটা WhatsApp নাম্বার থেকে গ্রাহকদের সাথে চ্যাট করতে পারবেন।

এটা Meta-র অফিসিয়াল **WhatsApp Business Cloud API** দিয়ে চলে। তাই নাম্বার ব্যান হওয়ার ঝুঁকি নেই, যেটা আনঅফিসিয়াল WhatsApp Web স্ক্র্যাপিং টুলে থাকে।

## ফিচার

- **মাল্টি-টেন্যান্ট SaaS:** প্রতিটা বিজনেস নিজে সাইন-আপ করে নিজের আলাদা workspace পায়। এক বিজনেসের ডেটা আরেক বিজনেস দেখতে পায় না।
- **টিম ও রোল:**
  - **মালিক (Owner):** সব কিছু করতে পারেন, অ্যাডমিন যোগ বা বাদ দিতে পারেন।
  - **অ্যাডমিন:** সব চ্যাট দেখতে পারেন, এজেন্ট যোগ বা বাদ দিতে পারেন, WhatsApp সেটিংস বদলাতে পারেন।
  - **এজেন্ট:** শুধু নিজের চ্যাট আর কাউকে অ্যাসাইন হয়নি এমন চ্যাট দেখতে পারেন।
- **শেয়ার্ড ইনবক্স:** রিয়েল-টাইমে মেসেজ আসে (SSE)। আছে অপঠিত মেসেজের সংখ্যা, সার্চ, আর আমার / অ্যাসাইন হয়নি / বন্ধ চ্যাটের ফিল্টার।
- **চ্যাট অ্যাসাইন:** অ্যাডমিন যেকোনো এজেন্টকে চ্যাট দিতে পারেন। কোনো এজেন্ট অ্যাসাইন-না-হওয়া চ্যাটে রিপ্লাই দিলে চ্যাটটা অটোমেটিক তার নামে চলে যায়।
- **২৪ ঘণ্টার নিয়ম:** WhatsApp-এর নিয়ম অ্যাপ নিজেই মানে। ২৪ ঘণ্টার উইন্ডো বন্ধ থাকলে শুধু অনুমোদিত **টেমপ্লেট** পাঠানো যায়, আর টেমপ্লেটের ভ্যারিয়েবলসহ প্রিভিউ দেখা যায়।
- **নতুন চ্যাট:** যেকোনো নাম্বারে টেমপ্লেট পাঠিয়ে কথোপকথন শুরু করা যায়।
- **মেসেজ স্ট্যাটাস:** ✓ পাঠানো, ✓✓ ডেলিভার হয়েছে, নীল ✓✓ পড়া হয়েছে। মেসেজ ব্যর্থ হলে তার কারণ দেখায়।
- **গ্রাহকের পাঠানো মিডিয়া:** ছবি দেখা যায়, আর ডকুমেন্ট বা ভিডিও ডাউনলোড করা যায়।
- **কুইক রিপ্লাই:** বারবার পাঠানো উত্তর এক ক্লিকে পাঠানো যায়।
- **ড্যাশবোর্ড ও অ্যাক্টিভিটি লগ:** কোন এজেন্ট আজ কতগুলো মেসেজ পাঠিয়েছে দেখা যায়। কে লগইন করেছে, কে কাকে যোগ করেছে, কে সেটিংস বদলেছে, সব লগে থাকে।
- **নিরাপত্তা:**
  - পাসওয়ার্ড scrypt দিয়ে হ্যাশ করা থাকে।
  - Access Token AES-256-GCM দিয়ে এনক্রিপ্ট করে রাখা হয়।
  - Webhook-এ `X-Hub-Signature-256` সিগনেচার যাচাই করা হয়।
  - কুকি HttpOnly।
  - লগইনে rate limit আছে।
  - কোনো সদস্যকে নিষ্ক্রিয় করলে সাথে সাথে তার লগআউট হয়ে যায়।
- **মোবাইল-ফ্রেন্ডলি UI:** পুরো ইন্টারফেস বাংলায়।

## চালানোর নিয়ম

এর জন্য Node.js **22.5 বা নতুন ভার্সন** লাগবে। আলাদা কোনো ডাটাবেস লাগবে না, Node-এর বিল্ট-ইন SQLite ব্যবহার হয়।

```bash
cd whatsapp-saas
cp .env.example .env        # দরকারি মানগুলো বসান
npm install
npm start                   # http://localhost:3000
```

ব্রাউজারে খুলে **"অ্যাকাউন্ট খুলুন"** চাপুন। প্রথম অ্যাকাউন্টটাই হবে মালিক (Owner)।

WhatsApp কানেক্ট করার আগেই ইনবক্স ট্রাই করে দেখতে চাইলে **সেটিংস → 🧪 টেস্ট মেসেজ** ব্যবহার করুন।

### সার্ভারে চালু করা (প্রোডাকশন)

VPS-এ এক কমান্ডে ইনস্টল করা যায়। এতে Docker সেটআপ আর অটোমেটিক HTTPS নিজে থেকেই হয়ে যায়। অথবা Render.com ব্যবহার করা যায়। ধাপে ধাপে নিয়ম আছে **[DEPLOY.md](DEPLOY.md)** ফাইলে।

```bash
curl -fsSL https://raw.githubusercontent.com/mhsiddiqui96/index.html/main/whatsapp-saas/deploy/install.sh | sudo bash
```

## WhatsApp কানেক্ট করা (Meta Cloud API)

১. [developers.facebook.com/apps](https://developers.facebook.com/apps) এ একটা **Business** টাইপের অ্যাপ বানান। তারপর অ্যাপে **WhatsApp** প্রোডাক্ট যোগ করুন।

২. **WhatsApp → API Setup** পেজ থেকে **Phone Number ID** আর **WhatsApp Business Account ID** কপি করুন। এখানে আপনার নিজের বিজনেস নাম্বারও যোগ করে নিতে পারেন।

৩. **Business Settings → System Users** এ গিয়ে একটা System User বানান। এই দুইটা পারমিশন দিয়ে তার জন্য একটা স্থায়ী (permanent) **Access Token** তৈরি করুন:
   - `whatsapp_business_messaging`
   - `whatsapp_business_management`

৪. অ্যাপে **সেটিংস** পেজে এই তিনটা তথ্য বসিয়ে সেভ করুন। তারপর **"কানেকশন টেস্ট"** চাপুন।

৫. **Webhook সেট করুন:** Meta App-এ **WhatsApp → Configuration → Webhook** এ যান।
   - **Callback URL** দিন: `https://আপনার-ডোমেইন/webhook`
   - **Verify Token** দিন: `.env` ফাইলের `WEBHOOK_VERIFY_TOKEN`-এ যা লিখেছেন, হুবহু সেটা।
   - তারপর **messages** ফিল্ড Subscribe করুন।

৬. `.env` ফাইলে `META_APP_SECRET` বসান। এটা পাবেন **App settings → Basic → App secret** এ। এতে সিগনেচার যাচাই চালু হবে।

> Webhook কাজ করার জন্য সার্ভারটা একটা পাবলিক **HTTPS** URL-এ থাকতে হবে। যেমন VPS + Nginx + Let's Encrypt, অথবা Render / Railway / Fly.io। লোকালি টেস্ট করার জন্য `ngrok http 3000` ব্যবহার করতে পারেন।

**SaaS হিসেবে চালালে:** সব বিজনেস একটাই Meta App আর একটাই Webhook URL ব্যবহার করে। কোন মেসেজ কোন বিজনেসের, সেটা payload-এর `phone_number_id` দেখে ঠিক হয়। প্রতিটা বিজনেস নিজের Phone Number ID আর Token নিজেদের সেটিংসে বসাবে।

## Environment Variables

| নাম | কাজ |
| --- | --- |
| `PORT` | সার্ভার কোন পোর্টে চলবে (ডিফল্ট 3000) |
| `SECRET_KEY` | টোকেন এনক্রিপ্ট করার গোপন কী। না দিলে `data/secret.key` ফাইলে অটো তৈরি হয়। |
| `WEBHOOK_VERIFY_TOKEN` | Meta webhook যাচাইয়ের টোকেন |
| `META_APP_SECRET` | Webhook সিগনেচার যাচাইয়ের জন্য (প্রোডাকশনে অবশ্যই দিন) |
| `GRAPH_API_VERSION` | Graph API ভার্সন (ডিফল্ট `v21.0`) |
| `ALLOW_SIGNUP` | `false` দিলে প্রথম অ্যাকাউন্টের পর নতুন সাইন-আপ বন্ধ থাকবে। শুধু নিজের বিজনেসের জন্য চালালে এটা দিন। |
| `COOKIE_SECURE` | HTTPS-এর পিছনে চালালে `true` দিন |
| `DATA_DIR` | ডাটাবেস কোন ফোল্ডারে থাকবে (ডিফল্ট `./data`) |

## প্রজেক্ট স্ট্রাকচার

```
server.js          Express অ্যাপ, স্ট্যাটিক ফাইল, .env লোডার
src/db.js          SQLite স্কিমা ও হেল্পার
src/security.js    পাসওয়ার্ড হ্যাশ, টোকেন এনক্রিপশন, webhook সিগনেচার
src/auth.js        সেশন, রোল-চেক, rate limit
src/whatsapp.js    WhatsApp Cloud API ক্লায়েন্ট
src/inbox.js       মেসেজ সংরক্ষণ, কে কোন চ্যাট দেখতে পারবে, রিয়েল-টাইম ব্রডকাস্ট
src/webhook.js     Meta webhook (যাচাই + ইনকামিং মেসেজ/স্ট্যাটাস)
src/api.js         REST API (টিম, সেটিংস, ইনবক্স, টেমপ্লেট, কুইক রিপ্লাই, স্ট্যাটস)
public/            বাংলা অ্যাডমিন প্যানেল (vanilla JS, কোনো build step নেই)
test/              API টেস্ট (npm test)
deploy/            VPS ইনস্টলার, ব্যাকআপ স্ক্রিপ্ট, Docker entrypoint
docker-compose.yml অ্যাপ + Caddy (HTTPS)
```
